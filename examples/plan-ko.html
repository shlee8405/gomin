로그인을 이메일 매직 링크로 바꿔요

비밀번호 재설정 문의가 전체 CS의 31%예요. 매직 링크로 바꾸면 이 문의가 사라지고, 기존 계정은 그대로 이어서 쓸 수 있어요.

예상 기간 4일변경 파일 9개마이그레이션 없음
핵심 요약
  • 무엇이 바뀌나: 로그인 화면에서 비밀번호 입력을 없애고, 이메일로 15분짜리 로그인 링크를 보내요.
  • 기존 사용자: 계정과 세션은 그대로. 비밀번호 로그인은 2주간 보조 옵션으로 남겨요.
  • 결정이 필요한 것: 메일 발송 서비스, 링크 유효 시간.
31%비밀번호 관련 CS 비중
4일구현 + 테스트
0DB 스키마 변경

흐름

sequenceDiagram
    actor U as 사용자
    participant W as 웹
    participant A as API
    participant M as 메일
    U->>W: 이메일 입력
    W->>A: POST /auth/link
    A->>M: 로그인 링크 발송
    U->>A: 링크 클릭 (토큰)
    A-->>W: 세션 쿠키 발급

진행 순서

  1. 토큰 발급 APIsrc/auth/link.ts에 1회용 토큰 생성 · 해시 저장 · 만료 처리를 추가해요.
  2. 메일 템플릿한국어/영어 템플릿 2종, 발송 실패 시 재시도 3회.
  3. 로그인 화면이메일 입력 → "메일을 확인해주세요" 화면. 비밀번호 로그인은 접어둔 링크로.
  4. 검증토큰 재사용 · 만료 · 다른 기기 클릭 시나리오 E2E 테스트.

이번에 포함

  • 기존 비밀번호 로그인 2주 유지
  • 발송 실패 알림
